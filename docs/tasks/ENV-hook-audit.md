- 상태: 진행 — 코드·합성 검증·발견 완료. 사용자 신뢰 완료 응답과 실제 untrusted 상태의 불일치 확인 중
- 단계·선행조건: Q04, Q03 완료. 기존 SessionStart Hook 발견·untrusted, 고정 검사 감사 완료
- 요청 근거·범위: 전체 순차 실행의 ENV-07. Hook 코드·정의 준비와 합성 검증은 기존 로컬 권한 적용
- 담당·독립 검토: root가 구현·통합, 보안 담당이 공개 코드 검토
- 입력: 공식 Hooks 문서(2026-10-21 확인), 현재 보안 정책·권한 프로필
- 소유 파일: `scripts/qh_hook_audit.py`, `tests/test_hook_audit.py`, `.codex/hooks.json`, 본 카드·증거
- 외부 변경: 없음. Hook 자동 신뢰·우회 플래그·자동 승인 반환 없음
- 검증 범위: 합성 payload로 시작·호출 전후·중단·종료·입력 및 저장 오류·원문 미노출 확인. 클라이언트 실제 실행은 사용자 신뢰 후
- 시간·비용: Hook timeout 3초, 모델·네트워크 호출 없음

## 산출물과 완료 기준

- 원시 입력·출력·명령·오류·계좌·토큰을 기록하지 않는다.
- 저장소 밖 사용자 전용 디렉터리에 고정 메타데이터를 배타 저장한다.
- 기록 실패를 성공으로 표시하지 않는다. PreToolUse 기록 실패에는 명시 deny를 반환하며 승인 allow는 반환하지 않는다.
- trusted 정의가 다른 코드로 바뀌지 않도록 코드 해시를 실행 명령에 고정한다.
- 실제 Hook 신뢰와 클라이언트 실행을 합성 함수 검증과 구분한다.

## 지원 범위

SessionStart·PreToolUse·PostToolUse·Stop·Interrupt·SessionEnd 이벤트를 준비한다. PostToolUse는 응답 관측이며 성공을 자동 의미하지 않는다. 명시적인 exit_code/isError가 있을 때만 결과를 분류한다. 누락된 종료는 성공으로 추정하지 않는다. hosted WebSearch 등 지원 밖 경로의 전수 기록은 보장하지 않으며 root가 작업 카드에 근거를 남긴다.

출처: [공식 Hooks 문서](https://learn.chatgpt.com/docs/hooks). Hook은 주문 권한·샌드박스·전체 감사의 대체가 아니다.

## 실제 결과와 다음 단계

- 코드·정의 6종을 작성·배치했다. 해시 고정 loader와 격리된 Python `-I -S` 실행을 사용한다.
- 독립 보안 검토의 모듈 가로채기·저장소 내부 감사 경로 문제 2건을 수정했고 재검토에서 해소를 확인했다.
- 전용 합성 테스트 8개, 전체 로컬 테스트 55개가 통과했다. root가 실행했으며 독립 테스트 담당의 실행으로 표시하지 않는다. 테스트 작성 중 블록 배치 오류 1건을 수정했다.
- 실제 클라이언트 config/read·hooks/list: 정의 6개 enabled, 모두 untrusted, 오류·경고 0. 모델 턴·Hook 신뢰 변경·실제 Hook 실행은 수행하지 않았다.
- [코드·정의 해시와 확인 결과](../evidence/env-hook-audit.json)를 보존한다. 임시 감사 파일은 장기 보존·동일 사용자 변조 방지·호스트 강제 종료 시 완전한 종료 기록을 보장하지 않는다.
- AP-02는 기존 SessionStart 단독 요청을 최종 v2의 6종 정의 신뢰 요청으로 교체했다. 사용자 신뢰 완료 후 새 세션의 SessionStart와 합성 도구 성공·실패 및 종료 이벤트를 확인한다. 자동 신뢰나 우회는 하지 않는다.
- 사용자가 2026-10-21 Hook 6개 신뢰 완료로 답했으나, 실제 사용자 상태 저장소의 재조회도 6개 모두 untrusted였다. 대신 등록하는 구체적인 위임 질문에 사용자가 **“내가 신뢰 등록 후 알림”**으로 답했다. root는 신뢰를 변경하지 않고 사용자 완료 알림 후 실제 반영·실행을 확인한다. 신뢰 DB 직접 편집이나 우회 플래그를 사용하지 않는다.
- 이미 승인된 로컬 준비는 완료했다. 실제 Hook 검증에는 신뢰 반영이 필요하다. Q05 Slack은 AP-01 명시 승인 후 실제 전송·수신 증거를 확보했으며 Q04 이후 큐 판정에 통합한다.

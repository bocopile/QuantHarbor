## 산출물과 완료 기준

- 비밀번호가 argv/env/로그/모델/공개 파일에 노출되지 않는 native 사용자 입력 경로.
- 저장소 밖의 새 AES-256 디스크 이미지, 명시 owner·권한·마운트 검증·잠금. 기존 볼륨/자료 변경 없음.
- 실패/취소/기존 경로/마운트 불명확 상태에서 중단하며 자동 덮어쓰기·평문 대체 없음.
- 암호화 여부·자기 이미지 device와 mount 결속·읽기/쓰기/잠금/재열기·합성 백업 복원 검증 결과를 비민감 상태로 남김.
- 실제 비공개 정책/키는 검증된 영역에 사용자 입력. empty template 복사와 정책/키 준비 완료를 구별.

## 현재 인계

- 일반/최종 보안 검토·품질75개·실제 합성 통합 통과. [실제 운영 시도](../evidence/paper-vault-operational-attempt-2026-10-24.json)는 create 실패이며 이미지/마운트가 없는 상태까지 확인했다. 운영 비밀번호/UI는 완료하지 못했다.
- 새 운영 시도 디렉터리만 보존하고 자동 재시도하지 않는다. 사용자는 현재 비밀번호 입력이 어렵다고 응답했다. 입력 가능한 시점의 사용자 알림을 기다리며 기존 승인은 유지한다. 이전 창 표시 여부와 실패 원인은 여전히 미확인이다. 키·정책·실제 API는 아직 다루지 않았다. 보안 SV1/SV2와 호스트 보정은 증거 기록을 따른다.

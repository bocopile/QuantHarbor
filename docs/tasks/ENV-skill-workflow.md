# ENV-skill-workflow — 제한된 역할의 Skill 적용과 인계

- 상태: 완료 — 명시 Skill 적용과 합성 인계 범위. ENV-11 전체 미완료
- 단계·선행조건: ENV-05·06·08·09·11의 내부 준비. 별도 부모 CLI 두 프로필의 고정 접근 검증 성공
- 요청 근거·실행 범위: 전체 순차 실행과 개발 팀·로컬 합성 검증에 대한 기존 요청
- 담당·독립 검토 여부: root가 범위를 고정하고 별도 읽기 전용 CLI에 qh_validator의 모델·추론을 적용; 결과를 root가 판독
- 입력 계약·설정 버전: 프로젝트 Skill 3개와 ENV-role-boundary 완료 증거의 권한 설정. 금융 계약은 변경하지 않음
- 소유 파일·통합: root가 본 카드·비민감 증거·현행 상태만 관리. 모델은 파일을 수정하지 않음
- 허용 도구·외부 변경: 지정된 공개 프로젝트 Skill·작업·상태 문서 읽기 1회. 앱·플러그인·MCP·웹·추가 agent 비활성. 기존 Codex 모델 통신만 사용
- 검증 요청 범위·환경: 이미 검증한 qh_review 부모 환경에서 제공된 합성 상황을 Skill 기준으로 분류하고 미완료·다음 작업 인계
- 시간·비용: 기존 구독만 사용, 120초, 자동 재시도 0, 신규 지출 없음

## 산출물과 완료 기준

- 세 Skill과 현재 상태를 실제 도구로 읽은 근거가 있다.
- 미확인을 미지원·통과·사용자 승인으로 바꾸지 않는다.
- ENV 중 금융 계약 구현으로 넘어가지 않고 개발 계약의 변경 영향만 분류한다.
- 파일 수정·외부 전송 없이 구조화된 결과를 반환한다.
- 설정 발견과 이번 명시 적용을 구분한다. 자동 Skill 선택이나 전체 대표 흐름을 완료했다고 하지 않는다.

## 인계

- 실제 변경: 본 카드와 비민감 증거 작성.
- 실제 확인: qh_review 부모 CLI, gpt-6-luna/high 지정, 120초·1회. 고정 읽기 도구 1회의 started/completed·exit 0과 입력 6개 불변을 바깥에서 확인했다.
- 결과: 현재 ENV/Q03, 미확인을 미지원으로 바꾸지 않음, 외부 자료 지시를 권한으로 승격하지 않음, 금융 계약의 선행조건 유지, 개발 계약 작성자 root, 자기/독립 검토 구분, Slack·Hook 미완료, 같은 로컬 허가 재질문 불필요 등 합성 분류 10개가 기대값과 일치했다.
- 증거: [실행 시점 입력 해시와 결과](../evidence/env-skill-workflow.json). 상태 문서와 본 카드는 실행 뒤 갱신되므로 당시 입력 해시를 최신 해시로 덮어쓰지 않는다.
- 판독: root가 실제 이벤트와 구조화된 최종 출력을 비교했다. 별도 독립 검증 담당의 실행이나 공급자 모델 식별 증명은 아니다.
- 미실행: 자동 Skill 선택, 모든 상황의 일반화, Hook 신뢰·실행·Slack 수신, 부모 앱 재시작.
- 다음: Q03 역할 업무 실행 경로의 완료 범위를 검토하고 Q04의 남은 Hook·감사 및 Q05·06으로 이어간다.

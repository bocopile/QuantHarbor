# ENV-validation — 개발 환경의 합성 자료 검증

- 상태: 지정된 로컬 권한 검증 완료 — ENV-11 전체 흐름은 진행
- 단계·선행조건: ENV-08·11; ENV-controls의 설정 로드 확인 후
- 요청 근거·실행 범위: 2026-10-20 사용자의 “전체 작업을 순차적으로 해줄수 없음?”을 앞선 실행 요청과 함께 반영한다. 계획에 필요한 로컬 구현·합성 검증을 순차 진행한다.
- 담당·독립 검토 여부: 주 담당 1명, 자기 검토. subagent를 실행하지 않는다.
- 입력 버전: 현재 프로젝트 권한 프로필, Codex CLI 0.162.1. 실행 결과에는 설정 SHA-256을 기록한다.
- 소유 파일: `scripts/validate_environment.py`, 이 카드, 비민감 검증 결과, ENV 관련 상태 문서
- 허용 도구·외부 변경: 로컬 합성 fixture·로컬 loopback만 사용. 계좌·실제 비밀값·Slack·유료 모델 API·원격 Git 변경 없음.
- 검증 범위: review/development 파일 읽기·쓰기·보호 경로·명령 네트워크 경계. 기존 세션 권한 변경이나 Hook 신뢰 변경 없음.
- 시간·비용: 각 하위 명령 15초 제한, 추가 유료 API 사용 없음. 실패 원인 변경 없이 같은 검증을 반복하지 않는다.

## 산출물과 완료 기준

- 실제 프로필을 선택한 명령으로 합성 파일 경계를 확인한다.
- 샌드박스 기동 실패와 접근 거부를 구분한다. 기동 실패를 권한 차단 성공으로 계산하지 않는다.
- 원시 로그·환경변수·사용자 파일 내용을 기록하지 않는다. 새로 만든 fixture만 정리한다.
- 통과는 검증한 명령 프로필에 한정한다. MCP·앱·모델·현재 대화 권한이나 모든 비밀 경로를 보장하지 않는다.

## 인계

- 최초 중첩 샌드박스 실행은 `sandbox_apply: Operation not permitted`로 실패했다.
- 별도 승인된 로컬 실행에서 `qh_review` 프로필로 고정 문자열 출력이 성공했다.
- 최종 `python3 scripts/validate_environment.py`는 종료 코드 0, 권한 검증 10/10 통과. 합성 파일과 임시 디렉터리를 정리했다. 네트워크는 sandbox 밖에서 접속 가능한 loopback listener를 양성 대조군으로 사용했다.
- [검증 결과](../evidence/env-validation-2026-10-20.json)에 시각·설정 해시·스크립트 해시·항목별 결과를 보존했다.
- 두 프로필에서 공개 합성 파일 읽기 허용, `logs` 아래 합성 파일 읽기 차단, `.codex` 신규 파일 쓰기 차단, loopback 접속 차단을 확인했다. 일반 workspace 쓰기는 review에서 차단, development에서 허용됐다.
- 현재 대화의 실제 코드 탐색 MCP 도구 이름 11개가 allowlist와 일치했다. 서버 호출로 그래프 조회가 동작했다. 다른 connector의 권한까지 검증하지 않았다.
- 역할 TOML 6개 필수 필드·모델 상속과 Hook의 정적 JSON payload를 확인했다. 역할 실행·Hook 실행·신뢰 변경은 하지 않았다.
- 실제 수행한 변경→자기 검토→검증→인계는 이 스크립트·카드·결과에 기록했다. 새 세션 재개나 독립 검토까지 성공했다고 표시하지 않는다.
- 사용자 선택: ENV 완료 조건을 유지하고 Slack 등 미완료 항목부터 처리. 다음 작업은 ENV-slack 및 Hook 신뢰·감사 확인이다.
- 후속: [ENV-runtime-controls](ENV-runtime-controls.md)에서 시간·재시도·완료 감사 기록을 보강하고 다시 검증했다. 이 카드의 최초 증거는 이전 스크립트 버전이며 최신 해시·실행 결과는 후속 카드의 증거를 따른다.

# ENV-development-budget — 현재 개발 팀의 비용·사용 경계

- 상태: 로컬 개발 정책 확정·독립 검토 완료. Q02의 역할·실행 상한 명확화 범위 완료
- 관련 작업: ENV-04, Q02. 투자 운영 AI·서버·데이터 비용 결정은 범위 밖
- 요청 근거: 사용자가 모델을 지정한 팀 구성과 전체 작업의 계속 실행을 명시했다. 현재 구독을 사용하는 동일 팀 작업의 진행 허가를 다시 요구하지 않는다.
- 담당: orchestrator 작성, 독립 검토 담당이 범위·완료 근거 확인
- 입력: 팀 설정, 실제 순차 위임 결과, 로컬 CLI 로그인 방식 조회, 계정 사용 한도 조회
- 소유 파일: 본 카드·개발 정책·승인 목록·상태·큐는 orchestrator 통합
- 외부 변경: 없음. 결제·크레딧 구매·구독 변경·API 키 설정을 하지 않는다.

## 적용 정책

- 현재 ChatGPT 로그인으로 이미 제공되는 Codex 사용 범위 안에서 개발 팀을 실행한다.
- 이번 개발 작업이 새로 승인한 추가 지출은 0이다. 새 유료 API runner, 크레딧 구매, 유료 서버·데이터 계약을 생성하지 않는다.
- 서비스가 사용 한도 도달·사용 불가를 반환하면 해당 실행을 중단한다. 다른 계정·API 키·추가 결제로 우회하지 않는다.
- 모델·추론 자동 상향과 재귀 위임 없이 전문 worker 1명을 순차 배정한다.
- 로컬 환경 검증의 명령별 15초·묶음 120초·재시도 0회는 기존 검증기가 집행한다. 별도 감사 실행기의 고정 시간 제한은 그 실행기를 통과한 호출에만 적용한다.
- 전체 모델 호출 시간·계정 청구 상한을 로컬 정책 파일이 기술적으로 강제한다고 주장하지 않는다. 별도 구매·결제 권한을 행사하지 않는 범위 제한과 서비스 사용 한도를 구분한다.

## 실제 확인

- `codex login status`는 ChatGPT 로그인을 반환했다. 인증값·자격증명 파일은 읽거나 저장하지 않았다.
- 계정 사용 한도 조회는 현재 일반 사용 가능, 현재 한도 도달 아님을 반환했다. 이 순간의 상태이며 다음 호출의 성공을 보장하지 않는다.
- 역할별 명시 모델/추론을 전달한 6개 agent의 실제 응답은 TEAM-bootstrap에 기록했다. 공급자 측 모델 식별·금융 성능 평가와는 별개다.
- 독립 검토 담당이 AUTH-02 적용과 추가 지출 0 경계의 타당성을 확인했다. Q02의 하위 범위 완료와 전체 ENV-04·격리·감사 완료를 구분하도록 검토했다.
- 계정 ID·요금제·잔액·상세 사용량은 저장소 증거에 넣지 않는다.

## AP-09 정정과 남은 결정

AP-09를 현재 구독으로 이미 승인된 팀을 계속 쓰기 위한 재허가로 취급한 것은 과도했다. 사용자 무응답을 승인으로 바꾸는 것이 아니라, AUTH-02의 기존 팀 실행 권한과 추가 지출을 하지 않는 보수적인 실행 범위를 적용한다.

향후 투자 운영 AI·서버·데이터의 월 예산 및 신규 비용은 AP-03과 해당 작업에서 별도로 정한다. 기존 구독 결제 조건이나 계정 청구 상한을 변경한 것은 아니다. 이 구분으로 ENV의 도구·격리·Hook·Slack 완료 조건을 생략하지 않는다.

# ENV-durable-audit — 로컬 검사의 시작·종료·실패·중단 기록

- 상태: 완료 — 고정 로컬 검사 감사 보강 범위. ENV-07 전체는 미완료
- 단계·선행조건: ENV-07·11의 로컬 준비. 기존 역할 계약·검증기·명령 경계 확보. Q02~06의 전체 완료나 ARC 착수를 의미하지 않는다.
- 요청 근거·실행 범위: 전체 작업 목록 완료까지 순차 진행하라는 사용자 재지시. 기존 로컬 구현·합성 검증 권한을 사용한다.
- 담당: orchestrator 통합, qh_architect → qh_implementer → 독립 검토 → 검증을 순차 배정
- 입력: ENV-runtime-controls, 현재 개발 정책·팀 설정·검증기
- 소유 파일: 구현 담당은 `scripts/run_local_check.py`, `tests/test_run_local_check.py`만, orchestrator는 본 카드·상태·증거 문서
- 허용 범위: 고정된 로컬 검사와 합성 fixture. 비밀값·개인 데이터·외부 호출·임의 명령·권한 변경 없음
- 시간·비용: 명령 시간 상한과 재시도 0회. 추가 유료 API runner 없음

## 산출물과 완료 기준

- 검사 전에 시작 기록을 저장하고 종료·실패·시간 초과·중단을 구분한다.
- 강제 종료로 종료 기록이 없으면 성공 대신 미완료로 판독한다.
- 원시 명령 출력·환경변수·예외 원문을 감사 파일에 저장하지 않는다.
- 임의 명령 실행과 감사 경로의 외부 이탈을 막는다.
- 합성 실패·중단·경로·출력 누출 검증과 독립 검토를 수행한다.
- 이 실행기를 거친 로컬 검사만의 감사이며 전체 Codex 도구 감사·Hook 실행·역할 격리의 증거로 확대하지 않는다.

## 인계

- 설계 담당의 읽기 전용 계약을 받아 별도 구현 담당이 두 파일을 작성했다. 고정 검사 2종, 저장소 밖 비공개 JSONL, 시작 fsync, 신호·시간 초과·프로세스 그룹 정리와 미완료 판독을 구현했다.
- 작성자 실행 `python3 -B -m unittest discover -s tests -p test_run_local_check.py`: 15개 통과, exit 0. 실제 team-config smoke·독립 검증은 아직 실행 전이다.
- 사용자 입력 대기는 해당 동작에 한정한다. AP-01 Slack, AP-02 Hook 신뢰는 미확정이며 본 작업으로 승인 또는 완료 처리하지 않는다. AP-09의 동일 팀 사용 재허가는 ENV-development-budget에서 과도한 요구로 정정했다.
- 기존 ENV 통과 조건은 유지한다. 다른 ENV 준비 작업과 ARC 구현의 선행조건을 혼동하지 않는다.

## 최종 결과

- 일반 검토에서 감사 입력 해시에 검사기가 읽는 문서 2개가 빠진 결함을 발견했다. `docs/execution-checklist.md`, `docs/approval-register.md`를 추가하고 각 문서 변경이 기록에 반영되는 회귀 테스트를 추가했다.
- 보안 검토 담당이 누락 수정과 고정 CLI·경로·권한·출력 폐기·불완전 기록 판독을 확인했다. 검토 범위에서 추가 실질 결함은 없었다.
- 독립 검증: 전용 합성 테스트 16개, 기존 제어 테스트 5개, 팀 검사 테스트 13개가 모두 통과했다.
- 실제 `run team-config`와 같은 UUID의 `inspect`가 모두 `success exit_zero`로 완료됐다. 출력에는 run ID·상태·고정 reason만 있었고, 저장소 밖 비공개 journal에서 start·terminal과 입력 해시 14개를 확인했다.
- [비민감 완료 증거](../evidence/env-durable-audit.json)에 검증 요약과 파일 해시를 남긴다. 실제 journal·로컬 경로·원시 출력은 저장소에 넣지 않는다.
- 새 검증기 실행은 명시한 고정 검사로만 제한한다. 실제 명령 프로필 10개 검증은 이번에 반복하지 않았다.
- 남은 한계: wrapper SIGKILL·호스트 종료의 terminal 보장, 이탈 session 후손 정리, 동일 사용자 변조 방지, 임시 기록의 장기 보존은 제공하지 않는다. start만 남은 기록은 실행 중인지 종료됐는지 추정하지 않고 `incomplete`로 표시한다.
- 다음: ENV-role-boundary의 제한된 부모 실행 경로 검증. Hook 신뢰·실행·지원 도구의 전체 감사와 Slack 연결은 별도 미완료다.

# A-DEC-003 — 남은 운용정책의 단계별 확정

- 날짜: 2026-10-23
- 관련 작업 ID: Q07, A02~06, ARC-01·02·06·07·09, Q23·26·27·30·32
- 상태: 채택 — 2026-10-23 사용자가 세 권고안 모두 선택
- 결정 담당·요청 근거: 잔여 작업 순차 진행 요청에 따라 root가 구체안을 작성하고 qh_architect가 읽기 자문. 사용자 명시 응답으로 정책·완료 범위 변경 채택

## 요구와 확인 사실

A-DEC-001·002의 상품·수동 환전·현금계좌·정규장·제외 범위·15분 분석·모의 후보별 사용자 승인은 이미 확정됐다. 같은 항목을 다시 묻지 않는다. 실제 자금·위험 수치, 전략·기간, 승인 세부·지속 운영값은 아래 관문에서 확정한다.

사용자 응답: “세 가지 모두 권고안으로 진행해줘. 자금·위험은 단계별로 확정하고, 전략은 비교안을 보고 선택할게. 초기에는 로컬 수동 운영으로 하고, 이후 잔여 작업도 순차적으로 진행하면서 내가 결정할 사항만 알려줘.”

기존 Q07은 A01~06의 운용정책 확정을 요구한다. 사용자가 세 묶음을 모두 선택했으므로 Q07의 해당 완료 범위를 **정책 구조·필수 필드·후속 확정 시점·미설정 시 실행 거부**로 변경한다. A02~06의 실제 운영값까지 모두 완료했다고 표시하지 않는다. A01의 상품 범위는 기존 확정 입력을 유지한다. ENV 선행조건과 이후 순차 실행 원칙은 바꾸지 않는다.

## 선택과 이유

### 1. 자금·위험 정책의 확정 시점

- 채택: 공개 문서에는 필수항목·단위·계산 기준·평가 기간·환경·초과 시 행동·책임을 정의한다. 실제 금액·비중·한도는 사용자가 비공개 설정에 입력한다.
- 필수항목: 총자금·시장 배분·통화별 현금 하한, 종목/업종/시장/통화 한도, 주문당/일간 한도, 거래량 참여 한도, 손실·낙폭 기준과 대응. 비중 분모·손실 기준점 등 계산 의미는 ARC에서 고정한다.
- 관문: 모의 API 연결·주문 전 모의 정책 확정(Q19 조회 연결 시점과 Q27 제출 중 더 이른 관련 연결 시점), 실전 진입 전 별도의 실전 정책 확정(Q31·32). 모의 정책을 실전에 자동 복사하지 않는다.
- 강제 요구: 필수값 누락·잘못된 단위·만료·환경 불일치·미승인 정책은 해당 환경의 주문 실행을 거부한다. 후보별 사용자 승인도 위험 검사를 면제하지 않는다.
- 대안: 정책값까지 지금 확정한 다음 진행한다. 실제 값은 공개 저장소·대화에 적도록 요구하지 않는다.

### 2. 투자·보유기간·리밸런싱 결정 방식

- 채택: 전략별 투자 목적·평가기간·예상 보유기간·종료 조건·정기/조건부 리밸런싱·기존 보유/미체결 충돌 처리를 비교안으로 제시하고 사용자가 선택한다.
- 관문: 전략 평가 시작 전 평가용 가정 고정(Q23). 모의 주문 전 적용 정책을 사용자가 확정(Q27). 비교·평가를 위임받았다고 특정 전략을 운용 채택하지 않는다.
- 승인 만료·가격 등 허용 변화 범위·변경 후보 재승인·철회/제출 경합·재가동 조건은 모의 API 전 정책 묶음에 포함한다. 15분을 이 값들로 자동 전용하지 않는다.
- 대안: 사용자가 투자 목적·기간·주기를 지금 지정한다. 지정되지 않은 항목은 미정으로 둔다.

### 3. 초기 운영·장애·복구 범위

- 채택: 초기 제품은 로컬에서 사용자가 시작·종료하는 모의 세션으로 정의한다. 가동 중에는 정규장 기본15분 분석과 주문 후보별 사용자 승인을 사용한다. 신규 유료 자원·서비스 비용은 0으로 둔다.
- 장애 시 신규 주문 제출을 중단하고 확인 후 수동 재개한다. 중단은 기존 미체결 취소나 청산을 뜻하지 않는다. 가능한 범위의 조회·대사·부분체결·상태불명·중단 후 체결 추적을 유지한다. 프로세스 종료 중 지속 감시는 보장하지 않는다.
- 초기에도 승인·주문·체결·대사 기록과 재시작 검사를 ARC-07·09에서 설계한다. 복구 근거가 부족하면 재개를 거부한다.
- 관문: 지속 모의 시작 전(Q30) 예산·운영 담당·감시 시간·보고 대상·보존·백업·복구시간·허용 데이터 손실 요구를 확정한다. 상시 운영 확대 시 다시 영향 확인한다.
- 기존 구독·보유 권리 또는 무료 자료로 요구를 충족하지 못하면 연결을 보류하고 비용 결정을 요청한다. 비용0은 모든 시세/API가 무료라는 주장이 아니다.
- 대안: 지금부터 상시 서비스 요구를 확정한 뒤 설계한다.

## 미확인과 재검토 조건

- 이 결정은 API 연결·계좌·모의 주문·실전 자금·외부 보고·예약 실행 권한을 추가하지 않는다. 실제 세션 실행은 해당 연결·실행 권한 확정 후다.
- 실제 금액·계좌값은 승인된 비공개 설정에 사용자가 입력하고, 키는 별도 자격증명 경로로 주입한다. 공개 검증 기록은 필수값 충족 상태만 남긴다. 아직 저장소 밖 운영 설정을 생성하지 않았다.
- 선택 범위를 [정책 관문](../policy-gates.md), plan·execution-checklist·큐에 반영하고 독립 검토 후 Q07을 판정한다. 후속 관문의 실제값·실행 결과는 미완료로 추적한다.
- 후속 관문 담당은 정책·값을 정하는 사용자와 추적·검사·미설정 차단을 통합하는 root다. 공급자 지원·비용·모의 결과와 요구가 충돌하면 사용자에게 재결정을 요청한다.

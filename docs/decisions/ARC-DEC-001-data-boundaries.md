# ARC-DEC-001 — 관측·원장·스냅샷의 책임 분리

- 날짜: 2026-10-23
- 관련 작업 ID: Q09·ARC-03·04, C·E·F·I-R
- 상태: 채택 — Q09 설계 범위
- 결정 담당·요청 근거: 확정 요구와 Q08 설계 선택에 따라 root 작성, qh_architect 읽기 자문

## 요구와 확인 사실

부분 조회·상태불명·가격 누락·중복 체결을 정상 잔고/평가/주문 없음으로 오인하지 않아야 한다. 실제 공급자 capability·권리와 정책값은 후속 관문 미완료다. 현재 금융 소스/DB는 구현하지 않았다.

## 선택과 이유

[공통 데이터 계약 v1](../contracts/data-v1.md)에 공급자 관측, 검증된 원장 사실, 버전 계산 스냅샷을 분리한다. 통화별 균형 현금 분개와 signed 수량 보조원장을 두고 분개 의미가 부족한 관측은 확정 원장으로 올리지 않는다. 법정 회계/세무 장부를 완성했다는 의미가 아니다.

단일 원장 쓰기 경로·고유키/내용 충돌 처리·정정 이벤트·transaction/outbox/inbox로 내부 중복 효과를 통제한다. 외부 API exactly-once는 주장하지 않는다. mutable 잔고 하나를 덮어쓰는 방식은 이력/대사 근거가 부족해 채택하지 않는다.

구성요소의 생산/소비·소유 데이터와 단위·시점·완전성·권리 계약을 명시한다. 실전 데이터를 읽어 설계를 확인하지 않고 합성 사례로 후속 구현을 검증한다.

## 미확인과 재검토 조건

Q10 목표/승인/주문·가용금 계산, Q11 권한/복구, Q12 canonical hash·구현 계약을 결합해야 한다. 실제 DB schema/migration·금융 테스트는 후속 구현이다. 공급자 필드 의미나 단위/시간/완전성의 변경은 version과 생산/소비·replay 영향을 재검토한다. 새 원가법·세무 방법·사용자 위험 수치를 이번 선택으로 채택하지 않는다.

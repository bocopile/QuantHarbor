# A-DEC-001 — 초기 상품·분석·환전 요구 입력

- 날짜: 2026-10-23
- 관련 작업 ID: A01·02·03, B01·02·06, ARC-01·02·06, A-input-preparation
- 상태: 채택 — 사용자 요구 입력만. ARC 최종 확정·연결/거래 권한 아님
- 결정 담당·요청 근거: 사용자가 세 가지 질문에 명시 응답, orchestrator가 통합

## 요구와 확인 사실

- 상품 응답: **“개별 주식과 일반 ETF를 초기부터 포함”**. 질문의 시장 범위는 한국·미국이다.
- 분석 응답: **“장중에도 반복 분석·후보 생성”**. 질문에서 실제 자동 주문 승인은 별도로 뒀다.
- 환전 응답: **“사용자가 환전하고 시스템은 현금 조회”**. 질문에서 실제 환전 실행 승인이 아님을 명시했다.
- 위 내용은 사용자 요구이며 공급자의 실제 API 기능을 확인한 결과가 아니다.

## 선택과 이유

사용자가 선택한 상품·분석 범위와 환전 책임을 초기 요구 입력으로 채택한다. 개별 주식만 우선, 장 마감 하루 1회 분석, 자동 환전 초기 필수라는 대안은 이번 초기 요구로 선택되지 않았다. 사용자의 구체적인 투자 이유나 수익 기대를 추정하지 않는다.

ETF의 세부 허용 범위와 장중 데이터·반복 호출 비용·후보 유효기간을 요구·설계 단계에서 구체화해야 한다. 수동 환전은 자동 환전 기능을 초기 필수에서 제외하지만 잔고·가용금·환전 반영 시점 확인 책임은 남는다. 운영 AI API 추가 비용이나 자동 주문 권한을 부여하지 않는다.

## 미확인과 재검토 조건

- ETF 세부 유형, 시장 세션, 계좌 유형, 정확한 수집/분석/주문 간격, 리밸런싱, 승인·위험·금액·예산은 미정이다.
- 증권사 권고는 기존 조사 시점의 조건부 제안이며 실제 공급자·계좌 검증이 남는다.
- 상품 범위·환전 책임·장중 주기가 바뀌거나 공급자 지원·권리·비용이 요구를 충족하지 못하면 관련 A/B/ARC 입력을 재검토한다.
- Q04 Hook 신뢰 선행조건과 사용자 직접 등록 선택은 바꾸지 않는다.

## 후속 결정

이 기록의 미확인·Hook 대기 설명은 당시 상태다. 후속 [A-DEC-002](A-DEC-002-initial-trading-policy.md)에서 계좌·정규장·제외 범위·15분 분석·모의 후보별 승인을 확정했다. Hook 위임·신뢰와 Q06 개발 ENV 판정은 완료됐으며 최신 진행은 status와 Q07 카드를 따른다.

# TARGET-DEC-001 — 합성 원천 근거를 분리한 후보 생성

- 날짜: 2026-10-24
- 관련 작업: Q24, EXEC-DEC-001
- 상태: 채택, 로컬 합성 범위
- 결정: root, 사용자 입력 없는 순차 실행 요청과 Astra/high 자문

Q21/Q19의 미확인 가용금/미체결 상태를 유지하고 별도 닫힌 합성 원천 사실에서만 시험용 목표/후보를 생성한다. Q23 연구 비교는 실제 전략 채택이 아니다. 기존 frozen 계약을 변경하지 않고 target-local-v1을 추가한다.

대안은 Q21 unknown을 알려진값으로 변경하거나 hash/boolean 확인만으로 후보를 허용하는 방식이다. 실제 근거와 합성을 혼동하므로 채택하지 않는다. 새 최적화 엔진 대신 명시 제안을 결정론적으로 검사하며 불가하면 원인과 함께 보류한다.

영향: Q26 candidatehash/표시/세대 binding, Q27 최신 위험·예약·DB 원자성이 이 추가 계약을 소비한다. 실제 자금/위험/전략/공급자권리 선택은 PG/SG에 남는다. 현재 구현·시험은 아직 미실행이다.

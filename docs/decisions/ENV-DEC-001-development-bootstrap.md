# ENV-DEC-001 — 프로젝트 범위의 개발 AI 환경

- 날짜: 2026-10-20
- 관련 작업: ENV-01~09
- 상태: 부분 대체 — 모델·추론·위임 방식은 ENV-DEC-003 적용, 나머지 로컬 경계·절차는 유지
- 근거: 사용자의 단계별 계획 진행 요청. 투자 시스템 ARC의 기술 선정은 포함하지 않는다.

## 선택

1. 전역 사용자 설정과 기존 프리셋은 유지하고 `qh_` 접두사의 프로젝트 역할을 둔다.
2. 모델·추론·provider·부모 권한은 상속한다. 기존 조사 모델을 실제 계정 검증 없이 고정하지 않는다.
3. 명시적 병렬 요청이 있을 때만 위임하며 자식 동시 실행 상한은 4, 기본 작성자는 1명이다.
4. 프로젝트 Skills는 `.agents/skills/`, 역할·세션 알림은 `.codex/`에 둔다. 운영키·투자 데이터는 넣지 않는다.
5. 작업 카드·결정 기록·상태 문서로 인계한다. 원시 실행 로그를 Git에 남기지 않는다.
6. Hook은 정적인 시작/재개 안내만 제공한다. 도구 감사·주문 정책 강제 기능으로 간주하지 않는다.

## 이유·대안·영향

전역 설정 변경은 다른 프로젝트에 영향을 줄 수 있어 프로젝트 범위를 선택했다. 모델별 성능·월 예산은 미확정이므로 상속으로 현재 사용 가능한 개발 세션을 유지한다. 개별 역할에 `sandbox_mode` 또는 `mcp_servers`를 넣어 별도 격리가 된 것처럼 표현하지 않는다. 실제 권한은 부모 세션·호스트 및 connector 정책에 달려 있다.

역할을 모두 별도 실행하는 방식은 비용과 파일 충돌을 늘릴 수 있어 기본으로 사용하지 않는다. 독립 검토가 필요하면 사용자 요청에 따라 별도 검토를 배정하고, 자기 검토와 구분한다.

## 미확인·후속

프로젝트 설정의 실제 클라이언트 로드, Hook 신뢰, 도구 최소 노출, 강제 비용 한도, 컨테이너·비공개 저장소, Slack, ENV-11 대표 검증은 완료되지 않았다. 이 결정만으로 ENV 전체를 통과시키지 않는다.

## 공식 근거

2026-10-20 공식 문서와 로컬 CLI 0.162.1의 도움말을 확인했다. 다음 문서는 변경될 수 있으므로 설정을 변경할 때 재확인한다.

- [Custom agents](https://learn.chatgpt.com/docs/agent-configuration/subagents): 프로젝트 TOML 역할, 모델 상속, 부모 권한 상속.
- [Build skills](https://learn.chatgpt.com/docs/build-skills): 저장소 `.agents/skills` 검색.
- [Hooks](https://learn.chatgpt.com/docs/hooks): 프로젝트 Hook 위치, 정확한 정의별 사용자 신뢰, 도구 적용 범위의 한계.

# ENV-DEC-005 — cmux 패널별 순차 작업·반환 절차

- 날짜: 2026-10-29
- 관련 작업 ID: PLAN-team-section-design-2026-10-29, PLAN-team-work-list-2026-10-29, Q27 재개
- 상태: 채택 — 기존 팀 정책을 구체화한 설계 기준. 실제 기동·행동 검증은 별도
- 결정 담당·요청 근거: root. 사용자 패널별 작업 설계 요청 및 분석 완료 후 실제 작업 재개 지시

## 요구와 확인 사실

- 역할별8패널은 안내 셸이며 자동 작업자/메시지 라우터가 아니다.
- 기존 team.toml은 worker1·writer1·순차 실행·재귀 위임 금지, ENV-DEC-004는 역할별 제한 부모 경로를 정한다.
- 전체 작업 목록과 역할 책임만으로 실제 입력·반환·오류/소유권 처리가 정해지지는 않는다.

## 선택과 이유

- 현재 대화의 root 한 명이 총괄하고01은 배정/상태 콘솔로 사용한다. 각 전문 패널은 작업별로 배정돼 별도 제한 문맥에서 실행·반환한다.08은 모델 없는 상태 표시다.
- task_id/run_id/revision/입력 manifest와 소유권을 배정·반환에 연결하고 root가 판정한다. 검토자와 구현자의 문맥/역할을 분리한다.
- idle 모델 호출·직접 peer 재배정·범용 자동 runner·새 분산 잠금은 도입하지 않는다. 자동화 없이도 구체적인 순차 실행을 관측·인계하는 범위다.
- 금융 계약·상위 큐·모델/권한 설정은 변경하지 않는다. 기존 ENV-DEC-004를 대체하지 않는다.
- 상세: [패널 설계](../team-section-design.md), [배정](../templates/team-assignment.md), [반환](../templates/team-result.md).

## 미확인과 재검토 조건

- 새 역할의 실제 기동·모델/권한/도구 적용·작업별 결과는 별도 확인해야 한다. 문서 작성은 실제 팀 흐름 검증이 아니다.
- 사용자 재개 지시 후 Q27 보존분·마지막 P2부터 순차 실행한다. 설계 당시 아직 실행하지 않은 결과를 통과로 기록하지 않는다.
- 동시 worker 확대·자동 라우터/보드/예약 운영·새 도구·권한 변경이 필요하면 기존 정책/승인과 영향부터 다시 정한다.

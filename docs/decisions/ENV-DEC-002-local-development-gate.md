# ENV-DEC-002 — 순차 진행의 로컬 개발 완료 기준

- 날짜: 2026-10-20
- 관련 작업 ID: ENV-04·07·08·10·11, ARC-01·11
- 상태: 미채택 — 사용자가 기존 ENV 통과 조건 유지를 선택
- 결정 담당·요청 근거: 주 담당 작성. 사용자의 전체 작업 순차 진행 요청

## 요구와 확인 사실

- 사용자는 환경 구축부터 전체 작업을 순차 진행하도록 반복 요청했다. 로컬 구현과 그에 필요한 합성 검증은 이 실행 범위에 포함한다.
- `AGENTS.md`의 최상위 작업 순서는 ENV 완료 기준 없이 다음 구현 단계로 넘어가지 않도록 정한다.
- 현재 `docs/plan.md`는 ENV-10의 승인된 Slack 채널과 ENV-11 검증을 ENV 완료에 포함한다. Slack 대상은 아직 정해지지 않았다.
- 권한 프로필의 합성 검증 10개가 통과했고 현재 대화의 코드 탐색 도구 11개가 설정 목록과 일치한다. 이 결과는 외부 서비스 권한이나 실전 격리를 검증하지 않는다.
- 세션 안내 Hook은 untrusted다. 안내 자체는 현재 AGENTS/Skill 절차로 수행하고 있지만 자동 실행은 확인되지 않았다.
- 위임 역할은 파일로 구성돼 있으나 현재 순차 단일 담당 방식에서는 실행하지 않았다. 자기 검토를 독립 검토로 취급하지 않는다.

## 선택과 이유

제안은 **로컬 개발 완료와 외부 운용 준비의 통과 조건을 분리**하는 것이었다. 사용자는 “현재 조건 유지: Slack 등 ENV 항목부터 완료”를 선택했다. 아래 제안은 적용하지 않으며 기존 통과 조건을 유지한다.

| 항목 | 로컬 개발 기준 제안 | 외부 운용 전 필요한 것 |
|---|---|---|
| 개발 비용 | 현재 대화에서 순차 수행, 새 유료 API runner·스케줄러 없음 | 외부 API 사용 전 공급자·월 예산·실제 차단 수단 결정 |
| 역할 | 주 담당 1명과 검토 결과 기록, 사용하지 않는 위임 설정은 미검증 표시 | 역할 실행 전에 클라이언트 발견·실행·권한 확인 |
| 감사·Hook | 작업 카드·입력 해시·비민감 결과로 개발 증거 보존 | 자동 Hook은 사용자 신뢰 이후 실행 확인; 운영 도구 감사는 별도 구현 |
| Slack | 로컬 알림 명세·전송 비활성 상태로 개발 | 승인된 수신 채널·정보 범위·전송 권한·연결 검증 |
| 운용정책 | 실계좌·금액·한도를 미설정으로 유지하며 합성 개발 가능 | 실계좌 연결·모의 API·실전 각각에 필요한 정책·권한 결정 |
| 주문 경로 | 미설정 정책 또는 capability면 실행 거부하는 계약 설계 | 계좌·키·한도·승인·대사·중단 검증 후 해당 환경만 활성화 |

이 안을 선택하면 ENV의 **로컬 개발 범위**를 평가한 뒤 ARC 계약을 정하고 로컬 구현으로 이어간다. ENV 전체의 외부 연결이나 실제 투자 준비까지 완료했다고 기록하지 않는다. 남은 항목은 사용 시점의 선행조건으로 추적한다.

대안은 기존 기준 유지다. 이 경우 Slack 대상과 Hook 신뢰 등 현재 ENV의 미완료 사항을 먼저 해소한다. 설계 입력은 준비할 수 있지만 ARC 확정과 애플리케이션 구현은 기다린다.

## 미확인과 재검토 조건

- 2026-10-20 사용자 응답에 따라 Slack 등 ENV 미완료 항목을 먼저 처리한다. 해당 응답을 임의 채널 생성·외부 메시지 전송 승인으로 확대하지 않는다.
- 사용자 금액·손실 한도·매매 주기·실제 증권사를 임의 확정하지 않는다.
- 로컬 프로필 검증을 모든 도구의 접근 격리나 모의·실전 안전성으로 확대하지 않는다.
- 이 안 채택 시 `docs/plan.md`, `docs/development-environment.md`, 작업 카드와 상태 기록의 통과 조건을 함께 갱신한다.

# BROKER-DEC-001 — 합성 조회와 실제 연결의 경계

- 날짜: 2026-10-24
- 관련 작업 ID: Q19, I01-R·I02-R·I08-R, Q20
- 상태: 채택 — 로컬 상세 구현 기준; 실제 연결 관문 미완료
- 결정 담당·요청 근거: 사용자 전체 순차 구현 요청, root 통합, qh_architect 읽기 자문

## 요구와 확인 사실

KIS는 첫 설계 대상이며 실제 계좌별 선정·지원은 SG-01 후속 확인이다. 공식 고정 커밋 cd63cae의20파일에서 조회9종을 조사했다.6종은 모의 TR 분기가 있지만 나머지3종의 모의 지원은 미확인이다. 페이지 완료와 같은 시점 계좌 일관성, 누적체결과 개별체결, 현금 원천 수치와 내부 가용금은 서로 다르다. [근거](../research/kis-read-contracts-2026-10-24.md).

## 선택과 이유

별도 synthetic 조회 binding·3개 canonical 등록형과 순수 KIS request plan/decoder·고정 합성 transport를 구현한다. 실제 host/auth/계좌번호 없이 오류·부분·scope·시점·해시·수량 의미를 검증할 수 있다. Q14 기동 차단과 Q12 frozen 계약은 유지하고 [추가 계약](../contracts/broker-read-v1.md)에 결속한다. 의존성 추가0·신규 유료0이다.

실제 HTTP/키 loader를 미리 활성화하는 대안은 채택하지 않는다. 구체 계좌·권리·정책·암호화 저장/주입 방식이 아직 없기 때문이다. 실제 terminal marker도 합성 종료 근거로 대체해 검증했다고 주장하지 않는다. 로컬 준비를 마치면 [구체 연결안](../development/paper-connection-preparation.md)을 제시하고 사용자 결정 후 같은 Q19에서 이어간다.

## 미확인과 재검토 조건

실제 API shape/종료/유량·ETF 지원·개별 체결 식별·현금 포함 관계·권리·비공개 정책/저장 프로필이 남아 있다. 이 값이 추가 계약과 다르면 실제 연결 전에 계약/구현을 수정·검토한다. 합성 성공만으로 Q19 완료 또는 Q20 진입을 선언하지 않는다. 본 결정은 토큰 발급·계좌 조회·주문·자금 사용 권한을 추가하지 않는다.

# ARC-DEC-003 — 로컬 수동 세션과 분리된 실행 권한

- 날짜: 2026-10-23
- 관련 작업 ID: Q11·ARC-07·09, C/D/J/M/K
- 상태: 채택 — Q11 설계 범위
- 결정 담당·요청 근거: A-DEC-003 초기 로컬 수동 운영·신규 비용0, root 설계

## 요구와 확인 사실

사용자 시작/종료와 후보별 승인, 장애 시 신규 제출 중단·수동 재개가 확정 요구다. 실제 운영 자원·계좌·키·보존/RTO/RPO는 아직 구축/검증하지 않았다.

## 선택과 이유

[operations-v1](../contracts/operations-v1.md)의 환경별 저장소/키·연구 격리·단일 broker egress·인증된 로컬 제어·활성 세션 스케줄을 설계한다. 초기 원격 승인/Slack 금융 승인/자동 failover/상시 daemon은 비활성이다. 같은 사용자 폴더 분리만으로 격리를 주장하지 않는다.

경보는 초기 로컬 제어 세션에서 확인하며 외부 전달은 별도 권한으로 추가한다. 원장 결과와 보고 전달을 분리하고 불명확 전달은 자동 재전송하지 않는다. 백업·복원은 금융 원장뿐 아니라 승인 소비/예약/불명확 주문을 함께 보존한다.

## 미확인과 재검토 조건

실제 런타임/이미지와 권한 강제는 Q13~14, 실제 모의 데이터 보호는 첫 연결 전, 지속 운영값은 PG04, 실전 자원은 Q31/PG05다. 무료 자원으로 경계를 충족하지 못하면 실행을 보류하고 필요한 사용자 선택만 요청한다. 초기 합성 복원 성공을 실계좌 복구 보장으로 확대하지 않는다.

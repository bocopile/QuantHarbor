# REPORT-DEC-001 — 합성 스냅샷의 로컬 보고

- 날짜: 2026-10-24
- 관련 작업: Q22 REPORT-local, EXEC-DEC-001
- 상태: 채택
- 결정 담당·요청 근거: root, 사용자 입력 없는 잔여 작업 순차 진행

## 요구와 확인 사실

Q21 로컬 평가/대사/스냅샷 독립 검토·검증 완료. operations-v1의 초기 보고 범위는 로컬 요청형 조회다. 실제 자료·계좌·전송 권한은 미완료다.

## 선택과 이유

검증된 snapshot을 보존하는 불변 보고·제한 메모리 저장·text/JSON CLI 표시를 구현한다. 표시에도 현재 report 권리를 재확인한다. unknown과 부분소계는 확정 숫자로 바꾸지 않고 실제 정정 predecessor를 조회한다. CLI는 제한 canonical stdin/stdout만 사용하므로 임의 파일탐색·private 접근·외부 전달을 추가하지 않는다. 웹서비스/자동보고 대신 기존 로컬 Python 진입점을 확장하며 신규 지출0이다.

## 미확인과 재검토 조건

실제 계좌 보고·내구성·투자보고 전송·예약·기간별 성과는 Q19/23/28 및 관련 관문에서 확인한다. Q22 합성 결과를 실제 대사/세무 보고 완료로 표시하지 않는다. 상세 계약은 reporting-local-v1이다.

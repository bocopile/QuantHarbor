# B-DEC-001 — 초기 설계 대상과 외부 연결 조건

- 날짜: 2026-10-23
- 관련 작업 ID: Q08·B01~06·ARC-08
- 상태: 채택 — Q08 설계 대상 선택 독립 검토 통과, 실제 연결·운영 채택 아님
- 결정 담당·요청 근거: 사용자 순차 진행·A-DEC-001~003에 따라 root 통합, qh_researcher 공식 조사

## 요구와 확인 사실

KR/US 현금계좌·정규장 주식/일반ETF, 제외 상품, 15분 분석·수동 환전·모의 후보별 승인·초기 로컬 수동/신규 비용0을 따른다. [현재 공식 근거와 선택표](../research/selection-2026-10-23.md)에 확인 사실·설계 판단·미확인·출처를 연결했다.

## 선택과 이유

- KIS를 첫 자체 BrokerPort 설계 대상으로, 키움을 대안으로 둔다. 양 시장 공식 경로와 환경 분리 예제를 활용하되 ETF 시세를 주문 지원으로 해석하지 않는다. 운영 브로커 확정은 SG-01·PG-01·AP-05 이후다.
- Python·PostgreSQL·Parquet를 설계 기반으로 사용하고 LEAN은 별도 연구 엔진의 직접 실행 검증 경로로 둔다. 유료 LEAN CLI는 비용0 정책에 따라 필수 구성에서 제외한다. 실제 버전·호환성은 SG-03에서 확인한다.
- 기존 OSS20개는 자체 요구에 맞는 패턴 참고 중심으로 적용하고 전체 포크·여러 주문 엔진을 도입하지 않는다. 직접 코드 복사·설치 권한/이용권을 조사 사실로 대체하지 않는다.
- 데이터는 합성 계약 검증부터 진행하고 실제 조회·시세·연구자료는 SG-01·02에서 조건을 확인한다. 외부 AI 제공권 미확인은 전송 금지로 처리한다.
- 운영 AI는 인터페이스·합성 응답을 먼저 구현하고 실제 호출은 SG-04 통과 전 비활성으로 둔다. 사용자 요청한 AI 기능을 삭제한 결정이 아니라 비용·권리·성능 확인 전 활성화를 막는 설계다.

## 미확인과 재검토 조건

SG-01~04는 모두 미완료다. 새 비용·계정 자격·ETF 지원·데이터 이용조건이 요구를 충족하지 못하면 구체적 대안을 사용자에게 전달한다. KIS 미확인을 키움의 지원으로 대체하지 않는다. 연구 엔진 직접 실행 검증이 실패하면 원인과 대안·추가 비용을 확인한 뒤 재선정한다. 의존성 버전 고정·설치·실제 API·계좌·주문·외부 전송은 이번 선택 문서화에서 수행하지 않았다.

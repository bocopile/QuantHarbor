# A-DEC-002 — 초기 거래 범위·분석 주기·모의 승인

- 날짜: 2026-10-23
- 관련 작업 ID: A01·03·05, ARC-01·02·06, Q07
- 상태: 채택 — 사용자 요구 입력. 실제 계좌 연결·주문·자금 사용 승인 아님
- 결정 담당·요청 근거: 사용자가 세 선택 질문에 명시 응답, orchestrator가 통합

## 요구와 확인 사실

1. 거래 범위: **현금계좌·정규장만, 신용·공매도·레버리지·인버스 제외**. 기존 한국·미국 개별 주식과 일반 ETF 범위에 적용한다.
2. 분석·주문 후보 생성: **기본 15분 간격**. 질문에서 시세 수집과 실제 주문 실행 주기는 별도 설계로 구분했다.
3. 초기 주문 운영: **모의투자 우선·주문 후보마다 사용자 승인**. 실제 계좌 연결·실전 주문·자금 사용은 별도 승인 전까지 차단한다.

사용자 응답은 제품 요구이며 특정 증권사·모의 API의 지원 사실이나 실제 연결 승인이 아니다.

## 선택과 이유

사용자가 선택한 범위를 초기 요구로 채택한다. 시간외 포함, 5분/60분 분석, 한도 내 모의 자동 실행은 이번 선택에서 채택하지 않았다. 투자 이유나 수익 기대는 추정하지 않는다.

정규장은 시장별 달력·시간대·휴장·조기폐장·서머타임을 구분한다. 정확한 지원 거래소·상품 허용 목록과 주문 유형은 후속 조사·설계에서 확인한다. 레버리지·인버스 제외를 모든 다른 ETF 유형의 허용으로 해석하지 않는다.

15분은 분석·후보 생성의 기본 간격이다. 승인 만료 시간, 데이터 허용 지연, 실제 주문 제출 간격, 가격 수집 간격이나 각 AI 역할의 호출 빈도를 자동으로 15분으로 설정하지 않는다. 주기 기준점·실행 겹침·시장 세션 경계 처리 등은 ARC에서 정의한다.

모의 주문 후보에는 사용자 승인이 필요하다. 승인은 대상 후보·환경·계좌·버전·행동에 묶도록 설계한다. 변경 후보·만료·철회·재사용 처리는 후속 계약에서 고정하며 여러 후보에 대한 포괄 승인이나 자동 승인으로 확대하지 않는다. 후보별 승인은 코드의 위험·데이터·가용금 검사를 대체하지 않는다.

## 미확인과 재검토 조건

- 자금·배분·현금 하한·위험 수치와 손실 대응, 투자/보유기간, 수집/주문/리밸런싱 기준, 승인 유효기간, 운영 예산·보존·복구 요구는 미정이다.
- Q07 전체 완료 기준은 유지한다. 이번 응답만으로 A01~06 전체·Q07·ARC를 완료 처리하지 않는다.
- 공급자 지원이나 비용·자료 이용조건이 요구와 상충하면 사용자에게 영향과 대안을 제시한다. 모의 지원 부재를 실전 API 사용으로 우회하지 않는다.

# ARC-DEC-004 — 구현을 위한 계약 v1 기준

- 날짜: 2026-10-23
- 관련 작업 ID: Q12·ARC-10·11, Q13 이후
- 상태: 채택 — 구현 계약 기준
- 결정 담당·요청 근거: 전체 순차 실행, Q07~11 독립 설계 결과를 root 통합

## 요구와 확인 사실

실제 운용값은 단계별 확정하고 전략은 비교 후 사용자가 선택한다. 이를 미정 전체 완료로 바꾸지 않으면서 로컬 합성 개발에 필요한 계약을 고정한다. 각 단계 검토 증거와 실제 미실행 한계는 작업 카드에 보존한다.

## 선택과 이유

[아키텍처](../architecture.md)와 data/execution/operations/serialization v1을 구현 정본으로 삼는다. Python domain/application/ports/adapters·runtime 의존 방향, root 공통 계약/설정/migration 통합, 한 worker/한 writer, 작업별 검토/실패 시험을 고정한다. canonical JSON은 등록 스키마·정확한 decimal·UTC 시각·불변 전체 payload·환경 구분 SHA-256으로 정의한다. 해시는 인증을 대신하지 않는다.

[구현 인계](../implementation-backlog.md)에서 Q13~36 각각 소유 경로·산출물·검증/관문을 연결한다. 모든 코드를 한꺼번에 생성하거나 합성 stub을 실제 연결/운영 완료로 집계하는 방식은 채택하지 않는다.

## 미확인과 재검토 조건

의존성/런타임의 구체 버전은 Q13 도입 시 SG03을 통과해 고정한다. 실제 공급자·정책·전략·모델·운영 권한은 기존 관문 미완료다. 원가법·성과 계산의 구체 알고리즘은 Q23/F07 명세에서 고정하며 임의 세무 결론은 내리지 않는다. 다음 단계의 완료 조건에 필요한 실제 자원/권한이 없으면 단계 완료를 보류하고 준비된 결과와 필요한 사용자 결정만 취합한다.

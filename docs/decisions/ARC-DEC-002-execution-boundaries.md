# ARC-DEC-002 — 후보별 승인과 단일 주문 전송 경계

- 날짜: 2026-10-23
- 관련 작업 ID: Q10·ARC-05·06, G/H/I/J/K
- 상태: 채택 — Q10 설계 범위
- 결정 담당·요청 근거: 사용자 후보별 승인·로컬 수동 운영, root 설계·qh_architect 읽기 자문

## 요구와 확인 사실

AI는 근거와 가설을 제공하며 자금·위험·권한의 정본이 아니다. 접수 결과가 불명확한 요청은 재전송 안전성이 입증되지 않는다. 공급자 capability·실제 정책 수치·외부 호출 권한은 미완료 관문이다.

## 선택과 이유

[execution-v1](../contracts/execution-v1.md)의 불변 후보·단일 소비 승인·예약·직렬화된 dispatch 전이를 채택 대상으로 한다. 제안/AI 검토/위험 검사/사용자 승인/외부 접수를 분리한다. 부분체결·취소 요청·상태불명을 독립 사실로 남기며 주문 outbox를 일반 메시지처럼 재전송하지 않는다.

통화별 원장 현금과 검증된 broker 매수가능액의 독립 상한을 비교하고 미체결 예약·미반영 차감을 중복 분류하지 않는다. 미확인 포함관계·음수 가용금은 차단한다. lease만으로 외부 호출을 막는다고 가정하지 않고 단일 egress와 수동 재개를 요구한다. 자동 failover·자동 정정/재주문·무제한 시장가 추정은 초기 경로에서 제외한다.

## 미확인과 재검토 조건

실제 가격·만료·비용·손실 수치는 PG-01/05, 전략 채택은 PG-03, broker 지원은 SG-01, 모델 활성화는 SG-04다. Q11의 실제 권한/egress 설계와 Q12 구현 명세를 결합한다. 이 설계는 금융 테스트나 계좌/API 실행을 수행한 증거가 아니다. 상태·상한·계좌 의미 변경 시 활성 주문 보존과 기존 승인 무효화를 함께 검토한다.

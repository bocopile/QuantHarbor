- 프로젝트명은 QuantHarbor이며, 사용자가 마련한 로컬 Git 저장소를 사용한다.

- **AI 제반환경을 먼저 구축하고, 아키텍처를 정의한 뒤 순차 구현한다.** 앞선 기능 중심 목록보다 이 순서가 우선한다.

- 사용자는 기존 대화의 내용을 프로젝트 문서로 저장하도록 승인했다.

- 이후 사용자가 orchestrator와 AI 팀 생성·역할 분리·모델/추론 설정·잔여 작업 순차 배정·필요한 중간 승인 요청을 명시했다. 전문 역할 위임과 독립 검토를 순차 수행하며 재귀 위임하지 않는다.
- 2026-10-23 사용자는 결과와 필요한 의사결정 중심 소통을 원하며 담당자별 작업도 볼 수 있게 요청했다. root가 지시·검토·수정·인계를 취합하고 [팀 작업 보드](team-dashboard.md)를 배정·착수·검토·완료·차단 시 갱신한다. 일상 진행 Slack 알림은 보내지 않고 결과·결정 필요·해결되지 않은 장애만 요약한다.

## 세션과 파일 상태

기존 대화 작업공간에는 커밋이 없는 `.git/`만 있었으며 작업 문서는 없었다. 대상 저장소에는 제목만 있는 README와 미추적 `.idea/`가 있었다. 기존 `.git/`와 `.idea/`를 복사·교체하지 않고 문서와 제외 규칙을 추가했다.

파일 저장은 Codex 앱의 대화·프로젝트 연결을 자동으로 변경하지 않는다. 새 작업공간을 사용할 때 경로와 쓰기 권한을 확인한다. 새 대화에서는 AGENTS.md와 이 문서를 읽고 이어간다.

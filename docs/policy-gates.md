# 운용정책 구조와 후속 확정 관문 v1

2026-10-23 [A-DEC-003](decisions/A-DEC-003-policy-gates.md)의 사용자 선택을 적용한다. 실제 수치·전략·연결 권한의 확정과 요구 구조 완료를 구분한다. 이 문서는 공개 요구 계약이며 실행 중인 정책 검사기나 실제 계좌 설정이 아니다.

## 모든 정책에 필요한 정보

정책 ID·버전, 적용 환경(합성/모의/실전), 계좌 바인딩의 비공개 참조, 적용 시각·만료, 사용자 결정 기록, 유효 상태, 필수값 검증 결과를 연결한다. 값만 있고 단위·계산 기준·행동이 없으면 유효 정책으로 보지 않는다. 연구·모의 정책을 실전에 자동 승격하지 않는다.

| 정책 묶음 | 필수 필드·단위 | 계산·평가 기준에서 고정할 사항 | 미확정/초과 처리 |
|---|---|---|---|
| 자금 | 총자금: 통화별 decimal 금액; 시장 배분·통화별 현금 하한: 금액 또는 비율과 기준통화 | 평가시점·환율·배분 분모·결제/미결제·미체결 예약금·매수가능액 구분 | 불완전 조회·부적합 정책이면 관련 위험 증가 주문 거부; 현금 임의 생성·환전 금지 |
| 집중도 | 종목·업종·시장·통화 노출: 비율 또는 금액 | 분류 버전·분모·평가가격·환율·미체결 포함 여부·주문 후 예상 노출 | 한도 없는 항목을 무제한으로 해석하지 않음; 초과 후보 제출 거부 |
| 거래 한도 | 주문당·일간 금액/수량, 거래량 참여 비율 | 일간 경계/시장 시간대·취소/체결 집계·거래량 관측창·정정 처리 | 단위/기간 미정이면 주문 불가; 초과분 임의 분할 제출 금지 |
| 손실·낙폭 | 금액 또는 비율, 평가 기간, 기준점 | 수수료·세금·실현/미실현·입출금 조정·고점 갱신·환율 영향 | 손실 행동을 사용자 확정; 신규 제출 중단과 취소·청산 분리, 미설정은 주문 불가 |
| 전략 | 목적·평가기간·예상 보유기간·종료 조건·정기/조건부 리밸런싱 | 데이터 버전·평가용 가정·비용·비교 기준·기존 보유/미체결 충돌 | 비교용 가정은 운용 채택 아님; 사용자 선택 전 모의 주문에 적용 금지 |
| 승인 | 후보·환경·계좌·버전·행동·유효기간·수량/금액 상한·허용 변화·철회/재사용 규칙 | 제출 직전 재검사·정책 변경·후보 변경·만료/제출 경합의 판정 시점 | 후보마다 사용자 승인; 잘못된 바인딩·만료·철회·불명확 상태는 제출 거부 |
| 복구·운영 | 담당·감시시간·예산 단위/기간·보존기간·백업주기·RTO·RPO·보고 대상 | 기록 내구성·불완전 실행 탐지·복구 검증·대사·사용자 수동 재개 | 초기 장애는 신규 제출 중단. 취소/청산 아님. 기록/대사 부족 시 재개 거부 |

금액은 정확한 소수 표현, 비율은 단위가 명시된 값, 시간은 기간 단위와 기준 시간대를 가진다. 세부 필드명·계산식·원장/승인 경합은 ARC-04·06·07·09에서 버전 계약으로 고정한다. 여기서 임의 수익 목표·손실 수치·투자 비중을 채우지 않는다.

## 추적할 관문

| ID | 확정/검사 시점 | 담당·필요 산출물 | 현재 상태·해제 증거 |
|---|---|---|---|
| PG-01 | 모의 API를 처음 연결하기 전(Q19 또는 더 이른 연결 시점), Q27 제출 전 재확인 | 사용자: 모의 자금·위험·승인 만료/허용 변화·철회·재가동 정책. root: 비공개 입력·단위/환경/버전 검사 | 미완료. 사용자 결정 참조와 값 미노출 검증 결과 필요. AP-05 연결 승인은 별도 |
| PG-02 | Q23 전략 평가 시작 전 | root: 비교용 목적·기간·데이터·비용·평가 가정 고정과 버전 | 합성 범위 명세 확정: RESEARCH-DEC-001·comparison-spec-v1.json. 실제 자료 평가/전략 채택 권한 아님 |
| PG-03 | Q27 모의 주문 전 | 사용자: 비교안에서 전략·기간·리밸런싱 선택. root: 정책 연결·PG-01 재확인 | 미완료. 선택 기록·모의 실행 권한·필수 정책 검사 필요 |
| PG-04 | Q30 지속 모의 시작 전 | 사용자: 운영 예산·담당·감시·보고 범위·보존·백업·RTO/RPO. root: 복구 검증·실행 권한 확인 | 미완료. AP-08·10 등 실제 실행/전송 범위 별도 |
| PG-05 | Q31 실전 연결 준비 및 Q32 실전 진입 전 | 사용자: 별도 실전 자금·위험·전략·기간·승인/중단 정책. root: 환경/계좌 바인딩·기동 거부·복구 검증 | 미완료. AP-05·07 별도, 모의 정책 자동 복사 금지 |

각 관문 미완료 시 PG-01은 모의 API 연결과 제출, PG-02는 전략 평가 시작, PG-03은 모의 주문 제출, PG-04는 지속 모의 시작, PG-05는 실전 연결/진입을 차단한다. 합성 개발·공개 조사는 차단하지 않는다. 정책 변경·만료·환경 변경·공급자 계약 변경 시 해당 관문을 다시 검사한다.

PG-01은 조회 전용 모의 연결에도 사용자와 합의한 조기 정책 확정 시점을 유지한다. 모의 API가 없으면 합성 구현만 가능하며 실전 API로 우회하지 않는다. 로컬 개발에 실제 금융값을 요구하지 않는다.

초기 운영 요구는 사용자가 켠 로컬 모의 세션, 정규장 중 기본15분 분석, 후보별 사용자 승인, 신규 유료 비용0, 장애 시 신규 제출 중단과 확인 후 수동 재개다. 조회·대사는 가능한 범위에서 계속하고 중단 뒤 체결도 추적한다. 앱 종료 중 지속 감시는 보장하지 않는다. 무료/기존 권리로 요구를 충족하지 못하면 연결을 보류하고 비용 결정을 요청한다. 실제 세션·예약·API 호출을 이번 문서화로 시작하지 않는다.

## 완료 집계

Q07은 A01의 범위와 A02~06 정책 구조·책임·확정 시점·미설정 거부, 정상/장애 수용 기준을 확인한다. A02~06의 후속 값·평가·운영 전체가 완료되는 것은 아니다. PG-01~05 상태는 각 후속 카드와 큐에 연결하며, 선행 정책이 미완료면 해당 연결·평가·제출·지속 운용·실전 진입을 시작하지 않는다.

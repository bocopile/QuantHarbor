| OpenDART | 일 한도는 약 20,000건(약관은 "허용량 제한 게시"만). 인증키 제3자 이용 금지·키 1개. 재배포·상업 이용·LLM 입력은 침묵. 접수일에 시각 없음(YYYYMMDD). |
| SEC EDGAR | 초당 10건, User-Agent에 회사명·연락처 선언. 사이트 데이터는 허가 없이 복제·배포 가능. LLM 입력은 침묵. |

## 4. 법·규제 경계 (변호사 확인 전 확정 금지)

법령은 국가법령정보센터 현행 시행본을 직접 열람했다.

- 본인 자금을 본인 계좌에서 프로그램으로 매매하는 것은 투자일임·투자자문의 구성요건(타인 자금, 일임 관계)에 해당하지 않는다고 읽힌다. 조문 문언에서 끌어낸 추론이며 당국의 명시 설명은 확인 못 함. 금융위 법령해석(2021)은 종목이 자동 선택되는 자동매매 프로그램을 영업에 쓰면 미등록 투자일임이라고 했다.
- 정보 제공은 AI 여부가 아니라 대가·개별성·채널이 기준이다. 유료·불특정 다수는 유사투자자문 신고, 개별·1:1·유료 양방향은 투자자문 등록. 미신고·미등록 제재는 조문상 한도가 크다(2차의 1천만 원 서술과 달라 조문 확인 필요).
- 법령에 "알고리즘" 문구는 없다. 전자적 투자조언장치 요건은 등록 자문·일임업자 대상이다. 시세조종·허수호가·반복 정정취소 금지는 개인에게도 적용된다.
- 개인 거주자가 국내 증권사로 해외 상장주식을 거래할 때 별도 신고는 필요 없다. 증빙 면제 한도(연 US$10만, 2025-12-29 개정)는 거래 시점에 재확인한다.
- 개인정보보호법은 본인 정보만 로컬 보관이면 해당 가능성이 낮고, 가족·지인 정보를 보관하면 달라질 수 있다.
- 레버리지·인버스는 사전교육과 예탁금 요건(단일종목은 현금 3천만 원)이 있다. 보도자료 간 시행일 표기가 달라 증권사 공지로 재확인한다. 현재 범위에서는 제외한다.
- 금융위 AI 가이드라인(2026-06)은 금융회사 대상 자율규제이며 개인 직접 적용 언급은 없다.

개인 단독 사용 가정이 깨지는 경우: 가족·지인 계좌로 대신 주문, 자금 합산 운용, 종목·비중을 타인에게 제공, 프로그램·키 판매·대여, 공개 채널 게시, 고속 인프라 사용, 레버리지·해외 직접 계좌 확장. 이 중 하나라도 해당하면 변호사 확인이 선행되어야 한다.
확인 못 함: 증권사 API 약관 원문, 본인 자동매매 적법성에 대한 당국의 명시 설명, 무상·가족 운용의 영업성 기준, AI 가이드라인 전문, 금융실명법·신용정보법의 개인 보관 쟁점.

(3)모의 호출 한도 값이 저장소마다 달라 코드 값이 아니라 공식 공지를 근거로 삼는다. (4)세율은 연도·시장 키 버전 스케줄로 두고, 세금·호가는 float이 아니라 정수 원 또는 Decimal로 처리한다. (5)밴드·정수 주식·현금 유입·비용·세금을 모두 구현한 허용 라이선스 저장소는 찾지 못했다. (6)한국 해외주식 양도세 구현은 SentinelQ 한 곳뿐이고 이동평균법·결제일 환율이 없다. 라이선스 없음·비상업·유지보수 중단으로 제외한 저장소는 20개 안팎이다.
한계: 코드 서술은 소형 모델의 소스 요약이며 줄 단위 재검증은 하지 않았다. 호가표·세율은 저장소 값이라 공식 자료로 검증하지 않았다.

플랫폼 함의: Trial Ledger 선행, "판정 불가(insufficient)" 기본값, 평가는 모델 공표 시점 이후(버퍼 포함)만 인정하고 시점은 미확인 상태 필드로 기록, 마스킹에 의존하지 않음, 허위정보 필터는 보조 경보로만 쓰고 "뉴스·게시글 단독 근거 매매 금지" 같은 구조적 규칙 적용, 모의 성과는 실행 경로 건전성 증거로만 인정.
문헌 충돌: 과최적화 규모(HLZ·HXZ 대 Jensen-Kelly-Pedersen), look-ahead 크기와 마스킹 효과, 감쇠 중 과적합 몫(McLean-Pontiff는 26%를 상한 추정). 모두 미국 팩터·특정 모델 맥락이라 한국 개별종목·소액 개인에게 이전할 근거는 없다.
확인 못 함: SSRN 본문 다수, Hansen·Romano-Wolf·White 본문, 한국어 리딩방 데이터셋, KIS 모의 체결 규칙, 신모델 기준 재평가, arch·skfolio의 실제 3.13 설치. 앞선 작업 목록의 La Morgia 수치는 "약 900건"으로 정정한다.

## 7. 작업 목록에 반영할 변경(제안)

- NX-TAX-COST-01: 세율은 연도·시장 키 버전 스케줄, 세금·호가는 정수 원/Decimal. 거래세 합계(코스피·코스닥 0.20%, 2026-01-01~)를 첫 스케줄 값 후보로 기록하되 세무 확인 전 확정하지 않는다.
- NX-TAX-COST-02: 양도세 통산 범위 정정 반영, 이동평균법·결제일 환율·연말 결제 귀속·ETF 구분을 전문가 확인 항목으로 유지. SentinelQ를 패턴 참고(코드 복사 아님)로 지정.

- NX-SECURITY-01: 단독 사용 가정이 깨지는 7가지 경우를 명시하고 확장 전 변호사 확인을 선행 조건으로 둔다. 시세조종·허수호가 방지를 위해 주문 빈도·정정취소 상한을 정책 검증 대상으로 추가(신규 제안).
- NX-BROKER-01: KIS 토큰 single-flight, 환경 enum과 TR_ID 매핑 표, fail-closed, 키·환경 쌍 검증, 유량 수치는 공식 공지 확인 전 설정 주입으로 둔다. 매도 체결 확인 전 매수 금지 상태 머신을 요구사항으로 명시.
- 데이터 공급원 메타데이터(재배포·캐시·LLM 입력 허용 태그, 확인일)를 NX-DATA-02의 선행 조건으로 추가. FRED는 약관 해소 전 후보에서 보류. 연구 전용이라도 Yahoo·KRX 자동 수집 경로는 채택 후보에서 제외한다.
- NX-AUTHENTICITY-02/03: Trial Ledger 선행, 합성 12시점은 DSR·PBO 입력으로 부적합, 소표본 "판정 불가" 기본값(연 SR 1.0도 수년 필요)을 DoD에 반영.
- 문서 주장과 코드를 대조하는 검사(README 수치·"세금 0" 같은 하드코딩 문자열)를 NX-OPS-INFRA-02 시험 설계 보강에 추가.

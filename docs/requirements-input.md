# 요구사항 입력과 남은 결정

기준일: 2026-10-23. ENV 중 수집한 입력을 Q07에서 구체화하는 문서이며 ARC 최종 명세나 거래 실행 승인이 아니다. 원본 작업은 [A01~06](execution-checklist.md)과 연결한다.

## 사용자 확정 입력

| 입력 | 사용자 응답·범위 | 관련 작업 | 이후 반영할 영향 |
|---|---|---|---|
| 시장·상품 | 한국·미국 개별 주식과 일반 ETF를 초기부터 포함 | A01, B01·02, E01, G01, I08 | 종목 구분·지원 범위와 ETF 관련 데이터/기업행동 확인 필요 |
| 분석·후보 생성 | 장중에도 반복 분석·주문 후보 생성 | A03, B02·06, E03, H01~08, J05 | 데이터 시점·지연, 호출 유량, 반복 후보 중복·만료, AI 호출 비용을 설계에서 구분 |
| 환전 책임 | 사용자가 환전하고 시스템은 현금 조회 | A02, B01, F03·05, I01-R·I02-R | 자동 환전은 초기 필수 기능이 아님. 통화별 잔고·매수가능금액·조회 시점을 구분 |
| 계좌·세션·제외 | 현금계좌·정규장만, 신용·공매도·레버리지·인버스 제외 | A01, B01, ARC-01·02, I08 | 시장별 세션과 상품 허용 목록·모의 지원 여부 확인 |
| 분석 기본 간격 | 15분 간격으로 분석·주문 후보 생성 | A03, B02·06, ARC-02 | 시세 수집·주문·승인 만료·데이터 신선도와 별도 |
| 초기 주문 운영 | 모의투자 우선·주문 후보마다 사용자 승인 | A05, ARC-06, J05, I | 자동 승인 없음. 모의 API 연결·실전 권한은 별도 |

근거는 2026-10-23 대화의 1·2차 질문에 대한 사용자 명시 응답이다. 후속 거래 범위·15분 분석·모의 후보별 승인은 [A-DEC-002](decisions/A-DEC-002-initial-trading-policy.md)에 기록했다. [A-DEC-001](decisions/A-DEC-001-initial-product-input.md)에 선택과 미확정을 기록했다. 장중 반복 분석은 초단타·실시간 스트리밍·장중 자동 주문의 승인으로 확대하지 않는다.

## 아직 결정하지 않은 사항과 필요한 시점

| 항목 | 현재 상태 | 결정이 필요한 시점·이유 |
|---|---|---|
| 일반 ETF의 세부 범위 | 레버리지·인버스 제외 확정. 일반 ETF 분류·제외 조건의 근거 확인은 Q08 기술 과제; 불명확한 구조는 편입 보류 | Q08 지원표·후속 종목 계약. 레버리지/인버스가 아니라는 이유만으로 일반 ETF로 인정하지 않음 |
| 거래소·세션·계좌 유형 | 현금계좌·정규장 확정, 실제 거래소/종목 지원 목록은 Q08 기술 확인 | Q08 및 ARC 계약. 불명확·미지원 환경은 허용 목록에 넣지 않음 |
| 데이터 수집·분석 간격 | 분석 기본15분 확정, 수집 주기·세션 기준점 미정 | A03/B02·06 전. 수집과 AI 호출을 같은 빈도로 가정하지 않음 |
| 주문·리밸런싱 주기 | 후보 생성 주기와 별개로 미정 | A03·05/ARC-06 전. 후보가 나왔다고 즉시 주문하지 않음 |
| 후보 승인·만료·철회 | 모의 우선·후보마다 사용자 승인 확정, 만료·철회 세부 미정 | A05/ARC-06 전. 계좌·제안 버전·유효기간·재사용 방지에 영향 |
| 자금·시장 배분·현금 하한 | 금액과 비중 미정 | A02/요구 확정 전. 실제 금액은 비공개 운영 설정에서 관리 |
| 위험 한도·손실 대응 | 종목/업종/통화·주문/일간 한도와 중단 조건 미정 | A04/요구 확정 전. 임의 숫자로 채우지 않음 |
| 수동 환전 후 반영 지연·외화 부족 | 상세 처리·사용자 안내 정책 미정 | A02·04/ARC-04·06 전. 조회 불완전이나 부족 현금을 주문가능으로 취급하지 않는 원칙은 유지 |
| 운영 예산·보존·복구 | 기존 개발 구독 사용 외 운영 정책 미정 | A06/B06·ARC-07·09 전. 신규 유료 자원은 AP-03 필요 |
| 증권사·데이터 연결 | 공급자·계좌·이용권·모의 실행 범위 미확정 | B/ARC 선정 및 AP-05 연결 직전. 실제 키는 대화·저장소에 입력하지 않음 |

사용자는 [A-DEC-003](decisions/A-DEC-003-policy-gates.md)의 세 권고안을 모두 채택했다. 실제 수치·전략·운영값은 [PG-01~05](policy-gates.md)에 정한 시점에 확정하며, 표의 과거 요구 확정 전 조건은 이 단계별 관문으로 대체한다. 신규 유료 비용0·초기 로컬 수동 운영·장애 시 신규 제출 중단/확인 후 수동 재개는 현재 요구다.

## 기존 조사와의 관계

2026-10-19 증권사 조사의 KIS 우선·키움 대안은 조건부 제안이다. 이번 수동 환전 선택으로 그 문서의 **자동 환전이 초기 필수일 때 키움을 우선 재평가**하는 조건은 현재 적용되지 않는다. 이것이 KIS 최종 선정이나 최신 기능 확인을 뜻하지는 않는다. 장중 반복과 ETF 지원, 계좌별 유량·현금 조회·데이터 이용조건은 B01~03에서 다시 확인한다.

현금계좌는 이번에 확정됐으며 매수 중심·일봉 기준 전략은 과거 설계 제안이다. 일봉 전략을 장중에 평가할 수 있는지와 별개로, 장 마감 하루 한 번만 분석하는 제품 범위로 고정하지 않는다. 분석 기본15분 외 데이터 해상도·전략·수집 주기는 후속 요구에서 정한다.

## 현재 실행 경계

2026-10-23 최신 명시 위임에 따라 Hook6개 정상 신뢰·실제 실행을 완료하고 Q06 개발 ENV 독립 판정을 통과했다. 현재 [Q07 요구·시나리오](tasks/ARC-requirements.md)를 진행한다. 거래 범위·15분 분석·모의 후보별 승인은 사용자 응답으로 확정했다. A02~06은 사용자 선택에 따라 정책 구조·책임·관문과 실행 거부 기준을 Q07에서 확인하고 실제값은 후속 관문에서 확정한다. 지원 목록은 Q08에서 검증하며 일반 ETF 여부가 모호한 구체적 상품군만 사용자에게 확인한다.

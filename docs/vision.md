# QuantHarbor 제품 철학과 범위

## 제품 철학

**투자의 모든 판단과 실행을 설명하고, 검증하고, 통제할 수 있게 한다.**

AI는 자료를 읽고 가설을 제시하며 검토한다. 사용자는 투자 목적과 허용 위험을 정한다. 시스템은 정해진 범위에서 일관되게 실행하고 결과를 기록한다.

핵심 가치는 **근거 있는 판단, 통제 가능한 실행, 축적되는 학습**이다.

## 일곱 가지 원칙

1. **사용자가 운용권을 갖는다.** 자금·대상·한도·자동화 범위를 사용자가 정하고 변경하거나 중단할 수 있다.
2. **모든 판단에는 근거가 있다.** 출처·데이터 시점·가정·반대 근거를 남기고 모르는 것은 명시한다.
3. **자산과 위험을 먼저 파악한다.** 보유·현금·미체결·집중도를 확인하고, 계좌나 데이터가 불명확하면 신규 위험 증가 주문을 보류한다.
4. **검증을 통해 자동화를 확대한다.** 연구·백테스트·모의·소액 실전에서 근거를 쌓는다.
5. **역할을 나누고 서로 검토한다.** 제안과 검토의 책임을 분리하고 한도·회계·주문 계산은 코드로 검사한다.
6. **실패를 전제로 설계한다.** 업무를 격리하고 연결 끊김·중복 요청·부분체결을 복구할 수 있게 한다.
7. **결과를 기록하고 배운다.** 손익·비용·판단 오류·사용자 개입을 기록하며 변경된 전략을 다시 평가한다.

## 사용자에게 하는 약속

내 자산이 어디에 있는지, 왜 이 판단을 했는지, 무엇이 실행됐는지, 언제 멈출 수 있는지를 알 수 있게 한다.

| 화면 또는 보고 | 답해야 하는 질문 |
|---|---|
| 제안 | 왜 제안했는가? 가정과 위험은 무엇인가? |
| 승인 | 어느 계좌에서 얼마까지, 언제까지 실행되는가? |
| 운영 | 무엇을 하고 있으며 이상은 없는가? |
| 결과 | 무엇이 달라졌고 비용과 오차는 얼마인가? |

## 범위

사용자가 요청한 범위는 한국·미국 개별 주식과 일반 ETF, 모의 및 실제 투자, 포트폴리오 저장·구성·리밸런싱, 일일 공부·자료 수집·매매·검토 AI팀, 업무 격리, GitHub·Skills·agents·MCP·Hooks 환경, Slack 연동이다.

2026-10-23 사용자는 일반 ETF 초기 포함, 장중 반복 분석·주문 후보 생성, 사용자 수동 환전·시스템 현금 조회를 선택했다. [요구 입력](requirements-input.md)을 따른다. 정확한 분석 간격·시장 세션·ETF 세부 유형과 실제 주문 빈도·권한은 아직 미정이다.

현금 계좌·매수 중심·일봉 전략은 초기 설계를 위한 제안이다. 투자금액, 시장별 비중, 허용손실도 미결정이다. 신용·공매도·파생·초단타·다른 국가 시장은 현재 구현 범위에 포함하지 않으며 확장 시 별도 결정한다. 장중 분석 선택을 초단타 또는 자동 주문 승인으로 해석하지 않는다.

## 기능 결정 기준

- 사용자의 판단을 더 명확하게 만드는가?
- 근거와 결과를 추적할 수 있는가?
- 실패 영향을 제한하고 중단·복구할 수 있는가?
- 복잡성과 비용에 비해 도움이 되는가?

수익 보장, AI 간 합의를 사실 검증으로 대체하는 방식, 근거 없는 종목 추천은 제품의 약속에 포함하지 않는다.

# QuantHarbor 계약 변경

현재 단계와 작업 ID를 먼저 확인한다. ENV 중에는 개발 작업 계약만 다루며 금융 애플리케이션 구현으로 넘어가지 않는다.

변경할 계약 버전과 생산자·소비자·소유 파일을 나열한다. 제안된 경로를 이미 존재하는 모듈로 표시하지 않는다.

금융 계약에서는 관련되는 항목을 확인한다: Decimal 금액/수량, 통화·단위, UTC/거래일/시장 시간대, 데이터 시점, 전체/부분 목표안, 미체결 예약금, 승인 대상·만료, 상태불명, 조회의 완전성, 중복·역순 이벤트.

공통 계약·DB migration은 한 작성자가 통합한다. 변경이 영향을 주는 작업·자료·검증과 호환/이행 방법을 기록한다. 테스트는 사용자 요청 범위에서만 실행한다.

독립 검토가 없으면 자기 검토로 표시한다. 보고는 변경 전후 동작, 근거, 실제 확인, 남은 확인, 인계 순서로 작성한다.

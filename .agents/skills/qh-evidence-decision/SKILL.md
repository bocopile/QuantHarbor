# QuantHarbor 근거 기반 결정

`docs/vision.md`, 해당 작업 ID, 기존 `docs/research/` 자료를 확인한다. 변경되지 않은 조사를 전부 반복하지 말고 결정에 필요한 미확인을 좁힌다.

- 사용자 요구 / 확인 사실 / 설계 선택 / 미확인을 나눠 기록한다.
- 공식 출처, 확인일, 가능하면 commit 또는 명세 버전과 해당 파일을 연결한다.
- 증권사 기능은 시장·환경·계좌 유형·REST/도구별로 구분한다. 미확인은 미지원과 다르다.
- 선택 이유·대안·영향·재검토 조건을 `docs/templates/decision.md` 형식에 담는다.
- 제안 단계와 채택 결정을 구분한다. ENV 통과 전 ARC의 최종 확정으로 처리하지 않는다.

스타 수·예제 존재·AI 합의는 실제 운영 품질의 증거가 아니다. 라이선스 확인은 확인한 파일 범위로 한정한다. 계좌 자격·비용·데이터 사용권은 추정으로 채우지 않는다.

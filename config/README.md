# 연결 설정

`connections.example.yaml`은 Git에 포함할 공통 설정 틀이다. 항목 추가·설명·형식 변경은 이 파일에 반영한다. 실제 채널·workspace·계좌 식별값과 비밀값은 포함하지 않는다.

`connections.local.yaml`은 예제에서 복사한 개인 설정이다. 기존 `.gitignore`의 `*.local.yaml` 규칙으로 최초부터 제외한다. 이미 추적한 파일에 ignore를 적용해도 추적이 중단되지 않으므로 실제 값이 있는 파일을 최초 커밋에 포함하지 않는다. 예제 변경을 로컬 파일에 반영할 때는 기존 값을 덮어쓰지 않고 필요한 새 항목만 추가한다.

실제 API 키·토큰은 저장소 밖의 접근 제한된 파일 또는 승인된 자격증명 저장소에서 관리하고, 사용할 프로세스에 필요한 환경변수만 주입한다. 예제의 `*_env` 값은 비밀값이 아니라 환경변수 이름이다. 토큰을 대화·문서·커밋에 붙여 넣지 않는다. 로컬 파일을 공유하거나 `git add -f`로 추가하지 않는다.

## 현재 준비 범위

- 공통 예제와 모든 연결이 비활성인 로컬 사본을 준비했다. 로컬 사본은 소유자만 읽고 쓸 수 있도록 생성한다.
- Slack 수동 connector는 기존 연결 인증을 사용한다. 그 인증 토큰을 복사하거나 내보내지 않는다. 이 파일을 준비한다고 connector 설정이 변경되지는 않는다.
- 직접 Slack API·증권사·시세·운영 AI API는 아직 연결하지 않았다. 설정 로더도 미구현이며 애플리케이션 단계에서 연결한다.
- `enabled: true`나 채널 ID 입력은 외부 전송·모의/실전 주문·새 비용에 대한 사용자 승인을 대신하지 않는다.
- 향후 로더는 필수 값 누락·알 수 없는 환경·해석할 수 없는 설정을 오류로 처리하고 해당 연결을 비활성화해야 한다. 실전으로 자동 전환하거나 비밀값을 로그에 출력해서는 안 된다.

현재 운영 예산·계좌·실전 설정은 미정이며 빈 값으로 둔다. 실제 연결 시 해당 작업의 승인 범위와 이용 조건을 확인한다.
